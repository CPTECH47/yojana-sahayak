“Accepted” means the gateway received the request. Confirm actual receipt on the test phone. Uncertain requests are never automatically resent.

This is an outgoing SMS demo with two curated guidance templates. It does not make eligibility decisions, find a verified nearest CSC, process incoming SMS or run an IVR.

Phone numbers stay in memory while a preview is active; the local ledger keeps a masked number and keyed hash. Gateway credentials remain in the private local configuration. The Android app and mobile operator keep their own records.

Setup: run npm run setup:phone in the project folder, then restart. Keep the gateway on a trusted local network.
